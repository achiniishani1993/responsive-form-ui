# ☕ Cafe Norra Website

A modern and responsive café website built using **HTML** and **CSS**, featuring a promotional video section, a CSS-only popup table reservation form, and a contact section with an integrated map.

This project demonstrates clean UI layout techniques using **Flexbox**, **Grid**, and pure CSS modal functionality without JavaScript.

---

## 📌 Features

- 🎥 Video hero section showcasing the café atmosphere  
- 🍽️ Table reservation popup form (CSS-only, no JavaScript)  
- 📅 Reservation options: party size, date, and time selection  
- 📩 Contact form for customer inquiries  
- 🗺️ Embedded map image section  
- 📱 Fully responsive design for different screen sizes  
- 🎨 Elegant typography using *Cormorant Garamond*
